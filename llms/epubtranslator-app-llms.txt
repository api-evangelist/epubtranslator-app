## What is EPUB Translator

EPUB Translator is an AI-powered e-book translation service at https://epubtranslator.app. It translates a complete EPUB chapter by chapter while preserving the original layout, styling and images, and returns a valid EPUB that opens in any reader. An account is required to translate a book; the exact price of that book is shown before any payment step.

EPUB Translator trains no models on uploaded books and does not sell or share them, but chapters are sent to a third-party large language model API to be translated and that provider's own policy reserves the right to train on API inputs and outputs, which is not a promise EPUB Translator can make on another company's behalf. Deletion is by email to support@epubtranslator.app; there is no self-serve delete button. Copyright in the translation belongs entirely to the uploader. ### Pricing

Pay per book, once. $0.004–$0.0125 per 1,000 characters with a $3.99 minimum per book; no plan, no recurring charge, and nothing is charged until the book's price has been shown. These are limited-time half-price rates, in effect through 2026-10-31 (UTC); the regular rate is $0.008–$0.025 per 1,000 characters with a $3.99 minimum. For a whole book this works out cheaper than translating it yourself by pasting chapters into a general-purpose chat assistant: there you pay again for the context each new request drags along, and again for every section you redo when the markup breaks. EPUB Translator sends each passage once with only the context it needs and reruns just the chunk that failed — an engineering difference, not a cheaper model. The pricing page exists in all 16 site languages — https://epubtranslator.app/en/pricing in English, https://epubtranslator.app/de/pricing in German, and so on for every language code listed above.

### EPUB Translator vs Direct LLM

Pasting a book into a general-purpose LLM usually breaks the EPUB: context limits force arbitrary cuts, markup comes back inconsistent, and the result is no longer a valid e-book. EPUB Translator combines the same LLM translation quality with engineering safeguards — EPUB-aware segmentation, structure preservation, and validation of the rebuilt file. [Why EPUB Translator vs direct LLM](https://epubtranslator.app/en/why-epubtranslator-vs-direct-llm)

## MCP Server (connect an AI assistant directly)

EPUB Translator runs a remote MCP server, so assistants that speak the Model Context Protocol (Claude Desktop, Cursor, and other MCP clients) can translate books directly. There is no API key to copy: add the endpoint, sign in with Google once in the browser window that opens, and the assistant works against the same account and balance as the website.

- **Endpoint**: https://epubtranslator.app/mcp
- **Transport**: MCP Streamable HTTP (stateless, JSON responses)
- **Authentication**: OAuth 2.1 authorization code + PKCE, federated to Google
- **Tools**: `list_supported_languages`, `create_upload_url`, `translate_epub`, `get_translation_status`, `check_balance`, `get_download_url`, `get_balance`
- **Typical flow**: pick a target language, hand over the book (upload or a public URL), start the translation, poll status, download the result

## EPUB Translator Agent Skill

EPUB Translator provides an Agent Skill that lets AI coding assistants (Cursor, OpenClaw, Claude Code, etc.) translate EPUB files via API. The Skill documents the full translation flow: pre-upload, upload, check cost, check balance, start translation, poll status, and download.

### How to download and use the Agent Skill

1. **Download the Skill files**: [SKILL.md](https://epubtranslator.app/agent-skill/SKILL.md) and [reference.md](https://epubtranslator.app/agent-skill/reference.md)
2. **Place files** in your AI assistant's skills directory:
   - **Cursor**: `.cursor/skills/epubtranslator-api/SKILL.md` and `reference.md`
   - **OpenClaw**: Add to the appropriate skills folder in your OpenClaw configuration
   - **Claude Code / other tools**: Place SKILL.md and reference.md where your tool loads agent instructions
3. **Get an API key**: Log in at https://epubtranslator.app/settings/api-keys and create an API key
4. **Provide the API key** to your AI assistant when it needs to call the EPUB Translator API

## API Overview

- **Base URL**: https://epubtranslator.app
- **Authentication**: `Authorization: Bearer <api_key>` or `X-Api-Key: <api_key>`
- **Main endpoints**: `/apis/file/pre-upload`, `/apis/file/upload`, `/apis/file/check`, `/apis/epub-translation/check-balance`, `/apis/epub-translation/start`, `/apis/epub-translation/status`, `/apis/file/download-url`
- **Target language codes**: `zh`, `zh-Hant`, `ja`, `fr`, `ar`, `es`, `ko`, `vi`, `id`, `pl`, `cs`, `it`, `de`, `pt`, `tr`, `ru`, `uk`, `en`
- **Output mode**: `outputMode` on `/apis/epub-translation/start` accepts `translated` (default) or `bilingual`
